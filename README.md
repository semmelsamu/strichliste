# Strichliste der FSIM

## Installation

See https://laravel.com/docs/13.x/installation

## Development

You may want to seed the database:

```sh
php artisan db:seed
```

You can reset the database with this command:

```sh
php artisan migrate:fresh --seed
```

## Deployment

See https://laravel.com/docs/13.x/deployment

Migrate the database like so:

```sh
php artisan migrate
```
